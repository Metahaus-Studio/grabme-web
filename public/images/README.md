# Editorial campaign imagery

## Current section-specific library

The website now uses 42 distinct images, with one image per section or interactive panel state. The authoritative mapping and bilingual alt text are in `src/lib/editorial-scenes.ts`. Thirty-nine section-named images were added after the initial three-image set below. Each has a 640px `-small.webp` version for mobile and a 1440px desktop version. See `SECTION-IMAGERY.md` and `evidence/image-uniqueness-audit.json` for assignment and verification details.

The initial `city-white`, `people-black`, and `cabin` images now belong exclusively to the homepage hero, driver invitation, and Connect introduction respectively. Unused initial variants remain preserved.

## Initial set

Generated specifically for this website with the built-in image-generation tool on 28 September 2026. These are conceptual campaign visuals, not photographs of verified GrabMe fleet vehicles or staff. The rendered figures identify them as illustrative.

- `city-white.webp`: white electric sedan in a Beirut waterfront setting, revised to reflect the user's white/black fleet direction with the original AION marketing asset as a shape reference.
- `people-black.webp`: driver on the opposite side of the open rear door while the passenger visibly enters a black electric sedan.
- `cabin.webp`: conceptual connected passenger cabin with abstract route display.

`city.webp` and `people.webp` are the initial generated variants, retained but no longer referenced by the site.

Original generated PNGs remain in the session's Codex generated-images directory. Project copies are 1440px WebP, quality 83, approximately 501 KiB combined. Original website assets are untouched.
